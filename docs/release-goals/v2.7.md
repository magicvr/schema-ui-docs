# v2.7 发布目标与 accept 门禁

本文档是 **v2.6 → v2.7** MINOR 的 **accept + 原子落地** 门禁清单。主题：**表单控件面进阶**（cascader / checkboxGroup / richText / password / defaultValue）。

权威 ADR：[0029](../decisions/0029-cascader.md) / [0030](../decisions/0030-checkbox-group.md) / [0031](../decisions/0031-rich-text.md) / [0032](../decisions/0032-password.md) / [0033](../decisions/0033-form-default-value.md)。迁移见 [migrations/2.6-to-2.7.md](../migrations/2.6-to-2.7.md)。

| 轨道 | ADR | capability | 说明 |
|---|---|---|---|
| 页面级表单进阶 | 0029–0033 | `form.controls.advanced` | 五件套同 MINOR |

---

## 1. v2.6 到 v2.7 的边界

### 1.1 版本与 dual-track

| 制品 | 版本字段 | 说明 |
|---|---|---|
| 页面 schema | `meta.protocolVersion: "2.7"` | 仅当页使用进阶字段集时要求 |
| 协议制品 | `artifactVersion: 2.7.0` / `protocolVersion: "2.7"` | 与根包、lockfile、MCP 对齐 |
| 应用清单 | 仍可为 `"2.5"`+ | 清单与页面版本继续解耦 |

- 未使用进阶字段的合法 **v2.6** 页面：可观测行为不变。

### 1.2 新增 capability 与字段集

| capability | 出现即要求 | 主要 type / 字段 |
|---|---|---|
| `form.controls.advanced` | 页使用下表任一 | 见下 |

| ID | 交付物 | wire 摘要 |
|---|---|---|
| F1e | `cascader` | path 数组 |
| CG | `checkboxGroup` | value 数组 |
| RT | `richText` | Markdown string |
| PW | `password` | string |
| DV | `defaultValue` props | 匹配字段 wire；record 覆盖 default |

### 1.3 明确不进 v2.7

- F2 嵌套/子表单；F3/F4/F5；多选 search query 放宽（仍 ADR-0010）
