# v2.8 发布目标与 accept 门禁

本文档是 **v2.7 → v2.8** MINOR 的 **accept + 原子落地** 门禁清单。主题：**Host/App 互操作**
（bootstrap 生命周期 / Host failure 结果与恢复 / Host conformance claim）。

权威 ADR：[0034](../decisions/0034-host-app-interoperability-boundary.md) /
[0035](../decisions/0035-host-bootstrap-lifecycle.md) /
[0036](../decisions/0036-host-failure-recovery.md) /
[0037](../decisions/0037-host-conformance-claim.md)。规范投影见
[10-host-interoperability.md](../10-host-interoperability.md)。迁移见
[migrations/2.7-to-2.8.md](../migrations/2.7-to-2.8.md)。

| 轨道 | ADR | capability | 说明 |
|---|---|---|---|
| Host bootstrap lifecycle | 0035 | `host.bootstrap` | 可选 bootstrap document、确定性启动生命周期、auth 归一化、manifest identity/缓存 |
| Host failure/recovery | 0036 | `host.failure-recovery` | 归一化 failure result、分类优先级、retry、return intent、A11y 最低义务 |
| Host conformance claim | 0037 | `host.conformance-claim` | 静态 claim、capability registry、evidence 制品 |

## 1. v2.7 到 v2.8 的边界

### 1.1 版本与 capability 门控

| 制品 | 版本字段 | 说明 |
|---|---|---|
| 页面 schema | `meta.protocolVersion: "2.8"` | 本批不新增页面字段集；算法类 fixtures 随制品线推进到 2.8 |
| 协议制品 | `artifactVersion: 2.8.0` / `protocolVersion: "2.8"` | 与根包、lockfile、MCP、validator 对齐 |
| 应用清单 | `"2.8"`（`pages[].returnIntentQueryKeys` 字段集） | 声明该字段的清单必须同时声明 `host.failure-recovery` capability |
| bootstrap document | `bootstrapVersion: "1.0"` | 独立 document 版本，不与页面/manifest 版本混用 |

- 未声明 `host.bootstrap` / `host.failure-recovery` / `host.conformance-claim` 的既有 Host：
  行为完全不变（不请求 bootstrap document、不产生 failure result、不产生 claim）；
- 未提供新 document 的 App：bootstrap 默认入口 `404/410` 即回退 ADR-0025 装载路径；
- 既有 401/403、Action 可观测结果与未知字段 fail-closed 规则原样保留。

### 1.2 新增 capability 与字段集

| capability | 出现即要求 | 主要交付物 |
|---|---|---|
| `host.bootstrap` | Host 选择进入确定性启动生命周期 | `host-bootstrap.schema.json`（B0）、bootstrap validator（B1） |
| `host.failure-recovery` | 清单出现 `pages[].returnIntentQueryKeys` | `host-failure.schema.json`（F0）、failure validator（F1） |
| `host.conformance-claim` | Host 选择出示可核验 claim | `host-conformance-claim.schema.json` + `capability-registry.json`（C0）、claim validator（C1） |

### 1.3 明确不进 v2.8

- 公共 branding/profile、download/job/realtime、tenant/context、telemetry/audit、完整
  accessibility preferences（ADR-0034 D7/D10 逐项处置）；
- 登录端点、token 字段、IdP 参数与凭据 transport（ADR-0034 D4）；
- claim 的签名/供应链 attestation profile（ADR-0037 明确后续）。
