# v2.6 发布目标与 accept 门禁

本文档是 **v2.5 → v2.6** MINOR 的 **accept + 原子落地** 门禁清单。主题：**表单控件面扩展（F1 批次 A+B）**。

权威 ADR：[0028](../decisions/0028-form-control-surface.md)。迁移见 [migrations/2.5-to-2.6.md](../migrations/2.5-to-2.6.md)。轨道见 [next-admin-lifecycle.md](./next-admin-lifecycle.md)。

| 轨道 | ADR | capability | 说明 |
|---|---|---|---|
| 页面级表单 | [0028](../decisions/0028-form-control-surface.md) | `form.controls.extended` | F1a–F1d；**C cascader = N/A defer** |

---

## 1. v2.5 到 v2.6 的边界

### 1.1 版本与 dual-track

| 制品 | 版本字段 | 说明 |
|---|---|---|
| 页面 schema | `meta.protocolVersion: "2.6"` | 仅当页使用 F1 字段集时要求（L2 下限） |
| 协议制品 | `artifactVersion: 2.6.0` / `protocolVersion: "2.6"` | 与根包、lockfile、MCP 对齐 |
| 应用清单 | 仍可为 `"2.5"` | 清单与页面版本继续解耦（ADR-0025 D1a） |

- Renderer `supportedVersions` 可同时包含 `"2.5"` 与 `"2.6"`。
- 未使用 F1 字段的合法 **v2.5** 页面：可观测行为不变。

### 1.2 新增 capability 与字段集

| capability | 出现即要求 | 主要 type / 字段 |
|---|---|---|
| `form.controls.extended` | 页使用下表任一 | 批次 A+B |

#### 批次 A — 已交付

| ID | 交付物 | wire 摘要 |
|---|---|---|
| F1a | `textarea` | string |
| F1b | `switch`、`checkbox` | boolean；缺省未交互 = `false`；`required` ⇒ 必须为 `true` |
| F1c | `radio` + 静态 `options` | 单值标量；MVP 无 `optionsSource` |

#### 批次 B — 已交付

| ID | 交付物 | wire 摘要 |
|---|---|---|
| F1d | `select.props.mode: multiple` | 值 = 标量数组；**禁止**用于 `form.mode: search`（L2） |

#### 批次 C — N/A defer

| ID | 交付物 | 状态 |
|---|---|---|
| F1e | `cascader` | **不进入 2.6.0** |

### 1.3 additive / 回归底线

- 合法 v2.5 页（无本包字段）：无新控件义务。
- 单选 `select`（无 `mode` 或 `mode: single`）：与 2.5 一致。
- ADR-0010 query 标量规则不因 F1d 放宽。

### 1.4 明确不进 v2.6

- F2 嵌套/子表单；F3/F4/F5；L1–L7；U*
- `cascader`、checkbox 组、富文本、password 专用 type、静态 `defaultValue` props

## 4. 版本纪律

v2.6 之后继续遵守 SemVer：文档勘误为 PATCH；兼容字段 / capability 为 MINOR；破坏合法输入或默认可观测结果为 MAJOR。F2 等必须先经独立 ADR，不回写本文件已关闭项。

## 5. 完成定义
