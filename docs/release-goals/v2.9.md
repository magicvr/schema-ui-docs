# v2.9 发布目标与 accept 门禁

本文档是 **v2.8 → v2.9** MINOR 的 **accept + 原子落地** 门禁清单。主题：**数据源路由绑定 +
表单字段只读**（下游 `schema-ui-core` 工作区 11 目标 15 GOAL-015 D-002 P-2 门禁 + 只读字段
通用需求）。

权威 ADR：[0039](../decisions/0039-data-source-route-binding.md) /
[0040](../decisions/0040-form-field-readonly.md)。迁移见
[migrations/2.8-to-2.9.md](../migrations/2.8-to-2.9.md)。

| 轨道 | ADR | capability | 说明 |
|---|---|---|---|
| 数据源路由绑定 | 0039 | `data.route-binding` | `data.params` / `optionsSource.params` / `datasources.*.params` 的 `$context.route.query.*` / `$context.route.params.*` 整值绑定（tombstone 删除，任意上下文） |
| 表单字段只读 | 0040 | `form.controls.readonly` | 字段 `readOnly` 声明：用户不可编辑、值仍参与提交投影 |

---

## 1. v2.8 到 v2.9 的边界

### 1.1 版本与 capability 门控

| 制品 | 版本字段 | 说明 |
|---|---|---|
| 页面 schema | `meta.protocolVersion: "2.9"` | 使用任一新 capability 的页面必须声明（L2 双重门控） |
| 协议制品 | `artifactVersion: 2.9.0` / `protocolVersion: "2.9"` | 与根包、lockfile、MCP、validator 对齐 |
| 应用清单 | `"2.9"`（无新字段） | 清单本身无新字段集；随制品线推进 |

- 未声明 `data.route-binding` / `form.controls.readonly` 的既有页面行为完全不变；
- params 值语法向后兼容：字面量与 `$deps.*`（表单上下文）规则原样保留；
- `$context.route` 在表达式挂载点（reactions / visibleWhen / permissions）仍禁止。

### 1.2 新增 capability 与字段集

| capability | 出现即要求 | 主要交付物 |
|---|---|---|
| `data.route-binding` | params 值含 `$context.route.(query\|params).*` 整值绑定 | 值语法扩展（ADR-0039 D1/D2）、tombstone 求值、request-construction fixtures |
| `form.controls.readonly` | 任一表单字段声明 `props.readOnly` | 字段控件 `readOnly` props（全部 14 个字段控件）、渲染义务（ADR-0040 D2） |

### 1.3 明确不进 v2.9

- `$context.route` 进入 reactions / visibleWhen / permissions（仍
  `FORBIDDEN_CONTEXT_NAMESPACE`；ADR-0039 D6）；
- `$context.route.path` 整值绑定（ADR-0039 D6）；
- `type: hidden` 与静态 `disabled` prop（ADR-0040 D5）；
- modal 内容树内的路由注入互操作门禁（沿用 ADR-0021 V280）。
