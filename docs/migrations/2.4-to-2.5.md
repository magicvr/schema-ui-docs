# v2.4 到 v2.5 迁移指南

v2.5 是 **向后兼容的 MINOR** 发布：新增应用级清单（ADR-0025）、应用导航（ADR-0026）与表格排序声明面（ADR-0027）。合法 **v2.4 页面**（无 `table.sort` 字段）与无清单宿主的可观测行为保持不变。

权威 ADR：[0025](../decisions/0025-app-manifest.md) / [0026](../decisions/0026-app-navigation.md) / [0027](../decisions/0027-table-sort-declaration.md)。发布门禁见 [release-goals/v2.5.md](../release-goals/v2.5.md)。规范正文：[17-app-manifest.md](../17-app-manifest.md)。

## 1. 版本声明与协商

### 1.1 页面

```yaml
meta:
  protocolVersion: "2.5"
  requiredCapabilities:
    - table.sort          # 仅当使用 sortable / sortField / defaultSort
```

| 页面字段 | 所需 capability | `protocolVersion` |
|---|---|---|
| `columns[].sortable` / `sortField` / `table.props.defaultSort` | `table.sort` | `"2.5"` |

- Renderer `supportedVersions` 应包含 `"2.5"`，并可继续支持 `"2.4"`。
- **L2 字段集下限：** 任一 table.sort 字段要求 `protocolVersion >= "2.5"` 且声明 `table.sort`。
- `legacy adapter`：旧 MAJOR 页面仍须在入口前显式转换；本 MINOR 不改变 adapter 边界。
- 既有 `query` / `pageSize` / `requestMapping` / `actions.upload` 语义不变。
- ADR-0011 的 `sort` wire、四层合并与 D4 状态表 **零修改**；0027 只补声明面与点击三态。

### 1.2 应用清单（可选）

```yaml
protocolVersion: "2.5"
requiredCapabilities:
  - app.manifest
  # - app.navigation   # 仅当出现 navigation 键
app: { appId: demo, name: Demo, homePageRef: home }
pages:
  - { pageId: home, title: Home, schemaUrl: /api/schema/home, route: /home }
```

| 清单字段 / 能力 | 所需 capability | 清单 `protocolVersion` |
|---|---|---|
| 消费清单 | `app.manifest` | `"2.5"` |
| `navigation` 键 | `app.navigation`（且须含 `app.manifest`） | `"2.5"` |

- 清单版本与页面版本**解耦**：清单 `"2.5"` + 页 `"2.1"`/`"2.4"`/`"2.5"` 混部合法。
- 不提供清单：页面级对接与 v2.4 完全一致。
- 有 `navigation` 无 `app.navigation` → M1 拒绝，不得部分解析。

## 2. 表格排序声明（opt-in）

未声明 `table.sort` 的页面：无协议级排序 UI 义务（不得猜列可排）。

需要可排序时：

```yaml
type: table
props:
  rowKey: id
  pagination: { mode: server, pageSize: 20 }
  defaultSort: { field: created_at, order: desc }
  columns:
    - { field: createdAt, label: 创建时间, sortable: true, sortField: created_at }
    - { field: amount, label: 金额, sortable: true }
```

- 三态：无序→asc→desc→清；`page` 重置 1；搜索保留 sort。
- 未知 sortKey → `TABLE_SORT_FIELD_UNKNOWN`，**不发请求**。
- 仅 `pagination.mode: server`。

## 3. 应用路由根 vs API baseURL

自 v2.5 起术语对齐：

| 用途 | 基址 |
|---|---|
| 清单默认入口、`schemaUrl`、相对 logo、DataRef/Action HTTP | API `baseURL` |
| `pages[].route`、navigate `url`、导航 `url`、`$context.route.path` | **应用路由根** |

`07` navigate 与 ADR-0021 D2 已改为应用路由根口径，不再写「API baseURL 下的前端 path」。

## 4. 无需迁移动作

- 合法 2.4 页面 YAML **无需修改**即可被支持 2.4+2.5 的 Renderer 继续渲染。
- 仅在需要排序声明、应用发现或导航互操作时 opt-in 新字段与 capability。
- 无强制 breaking rename 或字段删除。

## 5. Conformance

- 新 suite：`app-manifest`、`app-navigation`、`table-sort`（JS/Python dual）。
- 既有 `search-table`（0011）回归保持绿色。
- `version-negotiation` 增加 2.5 与 capability 向量；清单/页解耦正例。
