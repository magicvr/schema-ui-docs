# v2.5 到 v2.6 迁移指南

v2.6 是 **向后兼容的 MINOR** 发布：扩展表单控件面（ADR-0028，F1 批次 A+B）。合法 **v2.5** 页面（不使用新 type、不使用 `select.mode: multiple`）可观测行为保持不变。

权威 ADR：[0028](../decisions/0028-form-control-surface.md)。发布门禁见 [release-goals/v2.6.md](../release-goals/v2.6.md)。

## 1. 版本声明与协商

```yaml
meta:
  protocolVersion: "2.6"
  requiredCapabilities:
    - form.controls.extended
```

| 页面使用 | 所需 capability | `protocolVersion` |
|---|---|---|
| `textarea` / `switch` / `checkbox` / `radio` | `form.controls.extended` | `"2.6"` |
| `select` 且 `mode: multiple` | 同上 | `"2.6"` |

- Renderer `supportedVersions` 应包含 `"2.6"`，并可继续支持 `"2.5"`。
- **L2 字段集下限：** 任一上表字段要求 `protocolVersion >= "2.6"` 且声明 `form.controls.extended`。
- **legacy adapter：** 旧 MAJOR 页面仍须在入口前显式转换；本 MINOR 不改变 adapter 边界。
- 既有 `query` / `pageSize` / `requestMapping` / `actions.upload` 语义不变。
- 应用清单版本与页面版本继续 **解耦**；本 MINOR **不要求**清单升至 2.6。
- **不**交付 `cascader`（F1e defer）。

## 2. 从 Host 私有 type 迁到标准 type

| 常见 Host 私货 | 标准落点 | wire 注意 |
|---|---|---|
| `textarea` / `textArea` | `type: textarea` | string |
| `switch` / `toggle` | `type: switch` | **boolean**，非 `"true"` 字符串 |
| `checkbox` | `type: checkbox` | boolean；`required: true` ⇒ 必须为 `true` |
| `radio` / `radioGroup` | `type: radio` | 单值；静态 `options` |
| `select` + `multiple: true` | `select.props.mode: multiple` | 值是 **数组**；**不要**放在 search form |

## 3. 行为边界

- **单选 `select`：** 省略 `mode` 或 `mode: single` 时与 v2.5 一致。
- **多选 + 搜索表单：** L2 拒绝（`SELECT_MULTIPLE_IN_SEARCH`）。
- **query 序列化（ADR-0010）：** 不因本迁移放宽；boolean 在 search 中仍序列化为 `true`/`false` 小写。
- **recordSource：** 回填类型须匹配字段 wire；不匹配则跳过该键（`FIELD_WIRE_TYPE_MISMATCH`），不中止整表。

## 4. 不需要做的事

- 仅为「用到 2.6 Renderer」而把所有旧页改成 `"2.6"`——无 F1 字段的页可留在 `"2.5"`。
- 把多选数组塞进 search query 并期望跨实现一致。
- 期待 F2 子表、导入导出或 `cascader` 在 2.6 可用。
