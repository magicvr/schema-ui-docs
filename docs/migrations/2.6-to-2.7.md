# v2.6 到 v2.7 迁移指南

v2.7 是 **向后兼容的 MINOR** 发布：表单控件面进阶（ADR-0029–0033）。合法 **v2.6** 页面（不使用新 type、不声明 `defaultValue`）可观测行为保持不变。

权威 ADR：[0029](../decisions/0029-cascader.md) / [0030](../decisions/0030-checkbox-group.md) / [0031](../decisions/0031-rich-text.md) / [0032](../decisions/0032-password.md) / [0033](../decisions/0033-form-default-value.md)。发布门禁见 [release-goals/v2.7.md](../release-goals/v2.7.md)。

## 1. 版本声明与协商

```yaml
meta:
  protocolVersion: "2.7"
  requiredCapabilities:
    - form.controls.advanced
```

| 页面使用 | 所需 capability | `protocolVersion` |
|---|---|---|
| `cascader` | `form.controls.advanced` | `"2.7"` |
| `checkboxGroup` | 同上 | `"2.7"` |
| `richText` | 同上 | `"2.7"` |
| `password` | 同上 | `"2.7"` |
| 任一字段 `props.defaultValue` | 同上 | `"2.7"` |

- Renderer `supportedVersions` 应包含 `"2.7"`，并可继续支持 `"2.6"`。
- **L2 字段集下限：** 上表任一字段要求 `protocolVersion >= "2.7"` 且声明 `form.controls.advanced`。
- **legacy adapter：** 旧 MAJOR 页面仍须在入口前显式转换；本 MINOR 不改变 adapter 边界。
- 既有 `query` / `pageSize` / `requestMapping` / `actions.upload` 语义不变。
- 应用清单版本与页面版本继续 **解耦**；本 MINOR **不要求**清单升至 2.7。
- v2.6 的 `form.controls.extended` 字段集仍有效；进阶字段 **不**并入 `form.controls.extended`。

## 2. 从 Host 私有 type 迁到标准 type

| 常见 Host 私货 | 标准落点 | wire 注意 |
|---|---|---|
| 省市区 / 类目 cascader | `type: cascader` | **path 数组**（根→叶），非仅叶子 |
| 多选勾选组 | `type: checkboxGroup` | value **数组**（与 multi-select 同构） |
| 富文本编辑器 | `type: richText` | **Markdown string**；HTML 须 adapter |
| 密码框 | `type: password` | string；Host 遮罩 |
| 创建页默认值 props | `props.defaultValue` | 类型匹配 wire；recordSource 覆盖 |

## 3. 行为边界

- **search form：** 禁止 `cascader` / `checkboxGroup`（及既有 multi-select）。
- **defaultValue 序：** 空值 → defaultValue → recordSource → reactions（ADR-0033）。
- **richText：** 协议不消毒；Host 渲染 HTML 时负责 sanitization。
- **password：** 回填可写 string；Host 不得明文展示。

## 4. 不需要做的事

- 仅为「用到 2.7 Renderer」而把所有旧页改成 `"2.7"`——无进阶字段的页可留在 `"2.6"` 或更低合法 MINOR。
- 期待 F2 子表、导入导出在 2.7 可用。
